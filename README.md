# Credit Application System

A REST API for evaluating credit applications, built as a backend engineering study with Java, Kotlin and Spring Boot.

## Technology stack

- Java 17
- Kotlin
- Spring Boot
- Gradle
- H2
- Flyway
- REST API

## Purpose

The project models a credit evaluation workflow and provides a foundation for evolving the service with authentication, validation, persistence and additional business rules.

It is intentionally small enough to run locally while demonstrating common backend concerns such as domain modeling, API design and database migrations.

## Running locally

```bash
git clone https://github.com/arlss89/credit-application-system.git
cd credit-application-system
./gradlew bootRun
```

## Status

This is an independent learning project. The repository is kept public as a compact example of Java/Kotlin backend development.
